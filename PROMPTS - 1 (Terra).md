# Prompts used in this project

## 1. Playwright test framework

> https://loan-app.tallinn-learning.ee/small-loan Создай фреймворк автотестов на Playwright для этого приложения.
>
> Стек: Playwright + Typescript.
> Настрой команды запуска, конфигурацию Playwright.
> Организуй код с применением Page Object Model и atomic design.
> Создай папку pom внутрь которого положи папки atoms, organisms, pages для атомов, организмов и страниц. Обязательно создай base page и base atom.
> Тестам присвой уникальный номер. Например TL-20 - 1. Называй тесты на английском языке.
> Локаторы бери в первую очередь по data-tested.
> Проверь в том числе мобильные тесты.
> Методы должны быть не в тестах а в pom/atoms.
> Добавь поддержку прогонов на мобильных устройствах. Пусть будет только мобильный Chrome. Переменные, методы и тесты должны иметь читаемые названия.
> Все функции должны иметь свои переносы.
> Внутри expect не объявляй локатор. Объявляй локатор отдельно.
> Создай мне YAML файл для запуска этих автотестов, пусть будет, в GitHub Actions.
>
> Автоматизируй четыре сценария критического пути:
> 1. Откройте калькулятор и проверьте значения суммы, срока и ежемесячного платежа по умолчанию.
> 2. Измените сумму кредита и проверьте, что ежемесячный платёж пересчитался.
> 3. Нажмите Apply Now и проверьте, что открылась форма авторизации.
> 4. Введите данные авторизации и проверьте переход на страницу Loan Details.
